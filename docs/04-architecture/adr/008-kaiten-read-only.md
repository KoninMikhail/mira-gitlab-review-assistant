# 008. Kaiten строго read-only (личный токен)

- Статус: Принято (Accepted)
- Дата: 2026-06
- Контекст-ссылки: [../../03-reference/integrations-api.md](../../03-reference/integrations-api.md), [010-mr-kaiten-linking.md](./010-mr-kaiten-linking.md), [009-dry-run-publisher.md](./009-dry-run-publisher.md)

## Контекст

Mira читает из Kaiten описание задачи и **критерии приёмки** для ревью «в контексте
задачи» (FR-3.3). В MCP Kaiten технически доступны write-инструменты (`kaiten_create_comment`,
`kaiten_add_external_link`, смена статусов и т.д.).

Текущий `KAITEN_TOKEN` — **личный токен пользователя** (@dev.konin), не
сервис-аккаунт. Запись под личным токеном создаёт риски: действия от имени человека,
нарушение командного процесса (смена статусов — прерогатива людей), аудит «кто
писал».

## Решение

**Kaiten — строго read-only** на фазах PoC/MVP и под текущим личным токеном.

**Разрешено:**

- чтение карточки, описания, критериев приёмки, чек-листов, комментариев;
- REST `GET .../cards/...` или MCP `kaiten_get_*` / `kaiten_list_*` / `kaiten_search_*`.

**Запрещено** под этим токеном:

- любые create/update/delete/move/block/batch-операции в Kaiten;
- адаптер `src/adapters/tracker/kaiten/` реализует `TaskTracker` **только для чтения**.

**Запись обратной связи в Kaiten** (краткая сводка ревью в карточку) — допустима
**только после** заведения отдельного **сервис-аккаунта / бот-токена** (фаза 3+),
не под личным токеном. Без смены статусов карточки.

## Последствия

**Плюсы:**

- Безопасность и соответствие процессу команды;
- адаптер проще и предсказуемее;
- rule `kaiten-read-only.mdc` — жёсткое ограничение для агентов и разработчиков.

**Минусы:**

- Сводка ревью не дублируется в Kaiten на MVP (см. dry-run publisher);
- двусторонняя связь MR↔карточка через `kaiten_add_external_link` недоступна до
  бот-токена.

**Включает:** `KaitenTracker.getCard()` и чтение checklists через
`GET /cards/:id?additional_card_fields=checklists`; без `add_comment` в адаптере.

## Альтернативы

| Вариант | Почему отклонён |
| --- | --- |
| Write комментариев под личным токеном | Действия от имени человека; нарушение rule и аудита |
| Полный read/write через MCP «как есть» | Смешивает PoC-токен с прод-операциями |
| Отказ от Kaiten на MVP | Теряется проверка соответствия задаче — ключевая ценность Mira |
| Сразу завести бот-токен Kaiten | Организационная задержка; read достаточен для MVP |
