# Go — фокус ревью

Цель ревью — двигать код к enterprise-уровню (надёжность, безопасность,
тестируемость, явные контракты, безопасные дефолты), а **не** закреплять текущую
архитектуру — она будет переписана. Отмечай долгоживущие практики. Хвали удачные
решения; замечания подавай как возможность улучшить, с понятной выгодой и
небольшим посильным фиксом.

## Ошибки и ресурсы

- Проигнорированные ошибки (`_ =` без причины, отсутствие проверки `err`).
- Обёртка ошибок без контекста (`fmt.Errorf("%w", …)`), потеря исходной ошибки.
- Незакрытые ресурсы: отсутствие `defer Close()`, утечка тела ответа HTTP.

## Конкурентность

- Гонки: разделяемое состояние без мьютекса/каналов; запуск горутин без управления жизненным циклом.
- Утечки горутин: блокировка на канале без выхода; отсутствие `context.Context` для отмены.
- Неверное использование `WaitGroup`/буферизированных каналов; data race на map.

## Корректность

- Nil-map/nil-slice запись, паника на nil-указателе/интерфейсе.
- Захват переменной цикла в замыкании/горутине; копирование структур с мьютексом.

## Безопасность и качество

- SQL/командные инъекции; недоверенный ввод без валидации.
- Секреты в коде; слабый рандом (`math/rand` вместо `crypto/rand`) для токенов.
- Новые импорты без обновления `go.mod`; неэкспортируемое API в публичном пакете.
